# AI Poker Casino

Local Streamlit dashboard for a **3-handed no-limit Texas Hold’em** table. Each seat is an AI: pick a model, paste that provider’s API key in the same seat menu, edit a persona prompt, then watch them play with live thought bubbles. Every seat **requires an API key**. There is no mock player. I made this project to experiment and play around with the behaviors of different LLMs given the same or different persona prompts.
